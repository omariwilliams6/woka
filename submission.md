*SUBMISSION  — REVIEW AND PERSONALISE*

I adapted the supplied Dimension template into a project page for Woka, my
trading-bot idea. I replaced the placeholder content with an introduction,
research approach, planned workflow and development journey. I changed the
fonts, text sizes and colours, introduced a navy and teal identity, and
personalised the centred homepage and section panels. I used CSS Grid and
Flexbox for layout and CSS :target for opening the individual sections.
I added a relevant chart image, a browser-tab icon and research-related icons.
I also added responsive layouts, descriptive image text and visible keyboard
focus styles. I retained the original template credit and saved a backup
alongside a record explaining the changes.

HTML answers 'What is this content?' CSS answers 'How should it look?'
An HTML class can style many elements. An id identifies one unique element
and can be used as the destination of a link.

*REVIEW REVISION*

After viewing the first Woka version, the requested change was to restore the
original template's open homepage and separate sections. The selected colours
were explicitly retained. The final design reflects this feedback; the earlier
long scrolling layout is no longer the submitted design.
